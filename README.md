### Практические работы по дисциплине «Базы данных»

**Технологии:** MySQL, MySQL Workbench, C#, Windows Forms

**Изученные темы:**

### Практическая работа №1 – Инфологическое моделирование базы данных
- Разработка морфологического описания деятельности организации «Кинотеатр»
- Построение BPMN-диаграмм основных бизнес-процессов (продажа билетов, планирование сеансов)
- Заполнение таблиц сущностей, атрибутов, связей и ограничений
- Построение Crow’s Foot ER-диаграммы

### Практическая работа №2 – Даталогическое моделирование базы данных
- Создание ER-диаграммы в MySQL Workbench
- Реализация всех типов связей (1:1, 1:M, M:N)
- Определение первичных и внешних ключей, ограничений целостности

### Практическая работа №3 – Основы SQL. Создание и наполнение базы данных
- Работа в MySQL Command Line Client и MySQL Shell
- Создание базы данных, таблиц, первичных и внешних ключей
- Наполнение таблиц тестовыми данными (INSERT)
- Работа в графическом клиенте MySQL Workbench

### Практическая работа №4 – Основы SQL. Операции с БД
- Выборка данных (`SELECT`, псевдонимы, составные столбцы)
- Фильтрация (`WHERE`, логические операторы `AND`, `OR`, `NOT`)
- Обновление (`UPDATE`), добавление (`INSERT`) и удаление (`DELETE`) записей
- Работа с датами, строками и числовыми данными

### Практическая работа №5 – Разработка клиентского приложения
- Создание Windows Forms приложения на C#
- Подключение к MySQL через MySQL Connector/NET
- Реализация полного CRUD-интерфейса для 5 связанных таблиц (`clients`, `cashiers`, `sessions`, `movies`, `tickets`)
- Главное меню, DataGrid, формы добавления/изменения/удаления записей
- Удобный интерфейс с выбором из справочников и отчётами
