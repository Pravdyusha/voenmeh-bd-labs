### Репозиторий содержит практические работы по дисциплине **«Базы данных»**

**Технологии:** MySQL, MySQL Workbench, C#, Windows Forms, MySQL Connector/NET

## Изученные темы

### Практическая работа №1 – Инфологическое моделирование базы данных
- Анализ предметной области кинотеатра
- Разработка морфологического описания деятельности организации
- Построение BPMN-диаграмм основных бизнес-процессов (продажа билетов, планирование сеансов)
- Заполнение таблиц сущностей, атрибутов, связей и ограничений
- Построение концептуальной модели данных (Crow’s Foot ER-диаграмма)

**Отчёт** → [`practical-1.pdf`](docs/practical-1.pdf)

### Практическая работа №2 – Даталогическое моделирование базы данных
- Создание логической ER-диаграммы в MySQL Workbench
- Реализация всех типов связей (1:1, 1:M, M:N)
- Определение первичных ключей, внешних ключей и ограничений целостности

**Отчёт** → [`practical-2.pdf`](docs/practical-2.pdf)

### Практическая работа №3 – Основы SQL. Создание и наполнение базы данных
- Работа в консольных клиентах (MySQL Command Line Client и MySQL Shell)
- Создание базы данных и таблиц с помощью SQL-команд
- Определение первичных и внешних ключей
- Наполнение таблиц тестовыми данными (`INSERT`)
- Работа в графическом клиенте MySQL Workbench

**Отчёт** → [`practical-3.pdf`](docs/practical-3.pdf)

### Практическая работа №4 – Основы SQL. Операции с БД
- Выборка данных (`SELECT`, псевдонимы, составные столбцы)
- Фильтрация данных (`WHERE`, логические операторы `AND`, `OR`, `NOT`)
- Обновление (`UPDATE`), добавление (`INSERT`) и удаление (`DELETE`) записей
- Работа с датами, строками и числовыми данными

**Отчёт** → [`practical-4.pdf`](docs/practical-4.pdf)

### Практическая работа №5 – Разработка клиентского приложения
- Разработка Windows Forms приложения на C#
- Подключение к MySQL через MySQL Connector/NET
- Реализация полного CRUD-интерфейса для 5 связанных таблиц (`clients`, `cashiers`, `sessions`, `movies`, `tickets`)
- Удобный интерфейс с DataGrid, главным меню, формами добавления/изменения/удаления
- Выполнение запросов к связанным таблицам

**Отчёт** → [`practical-5.pdf`](docs/practical-5.pdf)
